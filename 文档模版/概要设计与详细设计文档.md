# 概要设计 / 详细设计文档

> 来源：《AI 时代程序员开发之道》第 4 章（UML 图 + 架构设计）；《AI 时代架构师修炼之道》

> 注：原书设计类内容多以 PlantUML 图 + 提示词示例呈现，无成文文档模板。以下为结合该书方法论整理的可复用设计文档骨架。

---

## 概要设计文档（HLD）

```markdown
# {{系统名}}概要设计文档

## 1. 引言
- 目的
- 范围
- 参考资料

## 2. 系统架构
{{架构图（C4 上下文图 / 容器图）}}

## 3. 模块划分
| 模块 | 职责 | 对外接口 |
|---|---|---|
| {{模块 1}} | {{职责}} | {{接口}} |

## 4. 接口设计（服务间）
{{服务通信、协议、消息}}

## 5. 数据架构
{{数据流、存储选型}}

## 6. 部署架构
{{环境拓扑}}

## 7. 非功能需求
- 性能 / 可用性 / 安全 / 可扩展性
```

## 详细设计文档（LLD）

```markdown
# {{模块名}}详细设计文档

## 1. 模块职责
{{模块功能边界}}

## 2. 类/组件设计
{{类图（PlantUML），职责与协作}}

## 3. 关键流程
{{时序图 / 活动图（PlantUML）}}

## 4. 数据结构
{{实体、字段、关系}}

## 5. 算法与逻辑
{{核心算法伪代码}}

## 6. 接口定义
{{函数签名、输入输出、异常}}

## 7. 异常处理
{{错误码、重试、回滚}}
```

## 常用 UML 图提示词

```
- 类图：请为 {{模块}} 绘制类图，用 PlantUML 语法
- 时序图：请为 {{场景}} 绘制时序图，用 PlantUML 语法
- 活动图：请为 {{业务流程}} 绘制活动图，用 PlantUML 语法
- 组件图：请为 {{系统}} 绘制组件图，用 PlantUML 语法
```
