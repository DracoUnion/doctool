# 项目计划书

> 来源：《AI 时代项目经理成长之道》第 6.1.1 节（ABC 移动支付产品开发项目示例）

---

## 9 项框架

```markdown
# {{项目名}}项目计划书

## 1. 项目概况
| 字段 | 内容 |
|---|---|
| 1.1 项目名称 | {{名称}} |
| 1.2 项目时间 | {{起止时间}} |
| 1.3 项目经理 | {{姓名}} |
| 1.4 项目团队 | {{团队构成}} |
| 1.5 项目投资预算 | {{预算金额}} |

## 2. 项目范围与目标
- 2.1 项目工作范围：{{范围描述}}
- 2.2 项目关键目标：{{目标 1、目标 2、目标 3}}

## 3. 项目进度计划
- 3.1 分阶段进度安排与甘特图
- 3.2 各阶段工作与交付内容
- 3.3 各工作负责人与时间节点

## 4. 项目资源计划
- 4.1 人力资源计划
- 4.2 技术资源计划
- 4.3 经费资源计划

## 5. 项目成本预算
{{预算明细与成本控制策略}}

## 6. 项目风险管理计划
- 6.1 风险识别（技术/人员/进度/成本/沟通）
- 6.2 风险评估（可能性 × 影响程度）
- 6.3 风险应对措施（避免/减轻/转移/承担）
- 6.4 风险监控与控制

## 7. 项目质量管理计划
- 7.1 质量政策
- 7.2 质量标准
- 7.3 质量管理流程
- 7.4 质量控制措施

## 8. 沟通管理计划
- 8.1 沟通目标
- 8.2 沟通内容
- 8.3 沟通对象
- 8.4 沟通方式
- 8.5 沟通频率

## 9. 变更管理计划
{{变更识别→评估→决策→执行→控制流程}}
```
