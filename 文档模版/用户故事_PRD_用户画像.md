# 用户故事 / PRD / 用户画像

> 来源：《AI 时代产品经理升级之道》第 2.1.2、3.3 节

---

## 用户故事（User Story）

```markdown
# 用户故事

作为 <{{角色}}>
我希望 <{{目标/能力}}>
以便 <{{价值/收益}}>

验收标准（Acceptance Criteria）：
- [ ] {{标准 1}}
- [ ] {{标准 2}}
- [ ] {{标准 3}}
```

示例：
> 作为 **注册用户**，我希望 **能按关键词搜索商品并筛选价格区间**，以便 **快速找到符合预算的商品**。

## 产品需求文档（PRD）

```markdown
# {{产品名}}产品需求文档（PRD）

## 1. 产品概述
- 产品名称
- 产品简介
- 产品背景

## 2. 目标用户
{{用户画像，见下}}

## 3. 功能需求
| 功能 ID | 功能 | 描述 | 优先级 |
|---|---|---|---|
| F-001 | {{功能}} | {{描述}} | {{P0/P1/P2}} |

## 4. 非功能需求
- 性能
- 安全
- 兼容性
- 易用性

## 5. 用户界面设计
{{页面/交互说明}}

## 6. 数据需求
{{数据采集、指标定义}}

## 7. 发布计划
{{版本、上线时间、推广}}
```

## 用户画像（Persona）

```markdown
# 用户画像

## 画像 1：{{低成本游学生群}}
| 维度 | 描述 |
|---|---|
| 人口特征 | 18~25 岁，低收入 |
| 兴趣 | 关注价格与体验性价比 |
| 产品使用 | 高频使用、价格敏感 |
| 消费能力 | 低 |

## 画像 2：{{深度体验白领群}}
| 维度 | 描述 |
|---|---|
| 人口特征 | 30~45 岁，中高收入 |
| 兴趣 | 注重个性化与高品质 |
| 产品使用 | 注重体验细节 |
| 消费能力 | 中高 |

## 画像 3：{{轻松休闲家庭群}}
| 维度 | 描述 |
|---|---|
| 人口特征 | 已婚，小有收入 |
| 兴趣 | 方便性、身边游 |
| 产品使用 | 家庭决策 |
| 消费能力 | 中 |

> 补充维度：资深 / 活跃 / 新晋 用户分类
```
