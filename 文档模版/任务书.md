# 任务书 / 项目任务书

> 来源：《AI 时代程序员开发之道》第 8.1.1、8.1.2 节（OA 办公自动化软件项目示例）

---

## 5 要素框架

| 要素 | 说明 | 填写示例 |
|---|---|---|
| **1. 任务目的** | 任务的最终目的与意义 | 提高企业办公效率，实现流程自动化，增强数据安全 |
| **2. 任务范围** | 软件类别、平台、功能模块、技术框架 | OA 软件（基本办公/流程管理/内部通信模块），Windows 平台 |
| **3. 任务要素** | 重要要素、关键点、难点 | 用户体系(工号)、公文流转、内部消息、接口对接(第三方系统)、移动端适配 |
| **4. 限制条件** | 人员、时间、预算、技术要求、安全性、质量要求 | 10 人团队，预算 500 万，6 个月内上线，质量达行业平均水平 |
| **5. 输出需求** | 成果的形式、格式、内容 | 上线版本软件、操作文档、技术文档 |

## 完整填写模板

```markdown

## 1. 任务目的
{{任务的最终目的与意义，如：优化性能、提升用户体验、增强数据安全}}

- 软件类别：{{OA / ERP / Web 应用 / 移动应用}}
- 平台：{{Windows / Linux / 跨平台}}

- 技术框架：{{如 Spring Boot + Vue、.NET + React}}

## 3. 任务要素
- 重要要素：{{关键功能点}}
- 关键点：{{技术难点或业务难点}}
- 难点：{{需要特别关注的部分}}

## 4. 限制条件
- 人员配备：{{团队规模与角色}}
- 时间预算：{{上线截止日期}}

## 5. 输出需求
- 成果形式：{{可运行软件系统}}
- 文档：{{操作手册、技术文档、API 文档}}

```
