# 会议记录 / 会议纪要

> 来源：《AI 时代项目经理成长之道》第 5.4、5.6 节（DBStar 项目进度汇报会议）

---

## 会议模板（会前使用）

```markdown
# {{会议主题，如"DBStar 项目进度汇报会议"}}

## 会议基本信息
| 字段 | 内容 |
|---|---|
| 会议主题 | {{主题}} |
| 时间地点 | {{YYYY-MM-DD HH:MM，地点}} |
| 主持人 | {{姓名}} |
| 与会人员 | {{姓名列表}} |

## 会议议程
| 时段 | 议题 | 主讲人 |
|---|---|---|
| 15:00-15:30 | 项目进度总结 | {{姓名}} |
| 15:30-16:00 | 研发进度报告 | {{姓名}} |
| 16:00-16:30 | 问题与风险讨论 | 全体 |
| 16:30-17:00 | 下一步安排 | {{姓名}} |

## 讨论内容
- 项目进度与里程碑完成情况
- 存在问题与应对措施
- 项目预算与资源消耗状况
- 项目规划与下一阶段工作安排

## 决策与行动项
| 决策/行动项 | 责任人 | 完成时间 |
|---|---|---|
| {{事项 1}} | {{姓名}} | {{日期}} |
| {{事项 2}} | {{姓名}} | {{日期}} |

## 问题讨论与会议总结
- Q&A
- 重申会议目的与成果
- 确认后续工作安排
```

## 会议纪要模板（会后使用）

```markdown
# 会议纪要

## 会议信息
| 字段 | 内容 |
|---|---|
| 主题 | {{主题}} |
| 时间 | {{YYYY-MM-DD HH:MM}} |
| 地点 | {{地点}} |

## 参会人员
| 姓名 | 职位 |
|---|---|
| {{姓名}} | {{职位}} |

## 会议内容
1. 议程介绍
2. 项目进展情况汇报
   - {{汇报要点 + 其他人员意见}}
3. 项目风险和问题
   - {{风险清单 + 应对措施}}
4. 下一步工作计划
5. 其他事项
6. 会议总结
7. 会议结束

## 会议成果
- {{成果 1}}
- {{成果 2}}

## 后续跟进任务（按角色）
| 角色 | 任务 | 负责人 | 截止时间 |
|---|---|---|---|
| {{角色}} | {{任务}} | {{姓名}} | {{日期}} |

> 本纪要由记录人撰写并在会后分发。
```
