## 供应商评价标准与评分表

```markdown
# 供应商绩效评价

## 评价标准（含权重）
| 标准 | 权重 |
|---|---|
| 产品质量 | 30% |
| 价格 | 20% |
| 交付准时性 | 15% |
| 服务质量 | 15% |
| 食品安全（适用行业） | 10% |
| 社会责任 | 10% |

## 评分表
每个标准下分 3~4 个评分项，0~5 分制；各项得分之和为该项得分；各标准按权重计入总分。

| 标准 | 权重 | 评分项 1(0-5) | 评分项 2(0-5) | 标准得分 | 加权得分 |
|---|---|---|---|---|---|
| 产品质量 | 30% | {{分}} | {{分}} | {{和}} | {{分×30%}} |
| 价格 | 20% | {{分}} | {{分}} | {{和}} | {{分×20%}} |
| 交付准时性 | 15% | {{分}} | {{分}} | {{和}} | {{分×15%}} |
| 服务质量 | 15% | {{分}} | {{分}} | {{和}} | {{分×15%}} |
| 食品安全 | 10% | {{分}} | {{分}} | {{和}} | {{分×10%}} |
| 社会责任 | 10% | {{分}} | {{分}} | {{和}} | {{分×10%}} |
| 合计 | 100% | | | | {{总加权分}} |

## 评审报告结构
一、供应商及产品简介
二、评审标准与结果
三、优秀或较差项目评语
四、总体评语与建议
五、报告编制
```
