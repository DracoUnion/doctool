---

## 风险管理计划框架

```markdown
# {{项目名}}风险管理计划

## 6.1 风险识别
- 6.1.1 技术风险：{{如关键技术未验证、性能瓶颈}}
- 6.1.2 人员风险：{{如核心人员流失、技能不足}}
- 6.1.3 进度风险：{{如需求变更、依赖延迟}}
- 6.1.4 成本风险：{{如预算超支、资源涨价}}
- 6.1.5 沟通风险：{{如需求理解偏差、协作不畅}}

## 6.2 风险评估
按 可能性（高/中/低）× 影响程度（高/中/低）评定风险级别。

## 6.3 风险应对措施
- 避免：消除风险根源
- 减轻：降低概率或影响
- 转移：通过合同/保险转移
- 承担：接受并预留应急资源

## 6.4 风险监控与控制
项目经理负责持续监控，发现新风险及时更新本计划。
```

## 风险评估矩阵（5×5）

```
影响程度
  高 │ R1  │ R2  │ R3  │ R4  │ R5  │
  中 │ R2  │ R3  │ R4  │ R5  │ R5  │
  低 │ R3  │ R4  │ R5  │ R5  │ R5  │
     ├─────┼─────┼─────┼─────┼─────┤
     低     中     中     高     高
               发生概率
```
> R1~R5 为风险等级，R5 最高。概率/影响可量化：低 < 30%、中 30~60%、高 > 60%。
