# 变更申请单 / 变更管理

> 来源：《AI 时代项目经理成长之道》第 6.7.1、6.7.2 节（社交视频 App 示例）

---

## 变更管理 5 步流程

```
识别变更 → 评估影响 → 决策 → 执行 → 控制
```
