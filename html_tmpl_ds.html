1. 关于这门课程

这是一门关于 软件工程 的进阶课程，主要探讨 Software as a Service (SaaS) 的架构设计与敏捷开发实践。通过本课程，您将学习到如何构建现代化的云端应用。

“敏捷开发不是一种方法论，而是一种思维方式。它强调快速迭代、持续交付和客户反馈。”

1.1 核心知识点

  • MVC 架构：模型、视图与控制器的分离。
  • RESTful API：设计无状态、可扩展的网络服务。
  • BDD/TDD：行为驱动开发与测试驱动开发。
    • RSpec 单元测试
    • Cucumber 集成测试

2. 代码示例

在 Rails 中，我们可以使用内联代码如 belongs_to :user 来建立关联。下面是一个完整的控制器示例：

class ArticlesController < ApplicationController
  def index
    @articles = Article.all
  end

  def create
    @article = Article.new(article_params)
    if @article.save
      redirect_to @article
    else
      render 'new'
    end
  end
end
